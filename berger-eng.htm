About Berger Tournament System

This standalone application maintains four separate tournament slots. Each slot has its own roster, schedule, results, selected round, tie-break setting, and withdrawal records.

  • Pairing numbers follow the order of names in the roster.
  • For an odd roster, the unused highest pairing number is a bye. A scheduled rest round awards no points.
  • In a double round-robin, the last two rounds of the first cycle are transposed. The second cycle uses the base schedule with colours reversed.
  • Sonneborn-Berger uses opponents' scores multiplied by points earned against them. Round-robin forfeits are included.
  • Direct Encounter averages repeated encounters with each opponent. It is reapplied to smaller tied groups when appropriate.
  • Progressive Score adds the player's cumulative score after each included round.
  • The selected tie-break is the only tie-break applied. Remaining ties share a position. Pairing number controls display order within an unresolved tie, not sporting rank.
  • Current standings include results through the selected round. Final standings include every round.

Withdrawal handling is an administrative convenience: existing results remain unchanged, while unrecorded games from the specified round receive forfeits. The application does not automatically annul earlier results.

Automatic saving uses this browser's local storage when available. Download JSON backups regularly. This application does not synchronize different devices or browser tabs.

Withdraw or reinstate a player

Recorded manual results are preserved. Unrecorded games from the effective round onward become forfeit losses for the withdrawn player. If both players are withdrawn, the result is a double forfeit.

Reinstatement removes automatically assigned forfeits that no longer apply. Manually entered results are not removed. No earlier results are automatically annulled.

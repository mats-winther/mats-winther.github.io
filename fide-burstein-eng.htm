About this implementation

Experimental bounded implementation of the FIDE Burstein System effective February 1, 2026. It is not FIDE-endorsed and must not be treated as a certified pairing checker.

The first half of the scheduled rounds, rounded down and capped at four rounds, are paired using the embedded FIDE Dutch engine. Subsequent rounds use the Burstein System.

The post-seeding pairing ranking is Buchholz, then Sonneborn-Berger, then ascending TPN. Player scores define the scoregroups but are not part of the in-bracket ranking.

The pairing-allocated bye is assigned before bracket pairing. Brackets are then searched in the candidate order prescribed by the Burstein rules, applying criteria C1 through C8 in priority order.

Pairing Index calculations treat an unplayed game as a game against oneself. The special treatment of consecutive trailing zero-point byes is applied when evaluating the scores used by actual over-the-board opponents.

Pairing searches use fixed time and node limits. An interrupted search never publishes a provisional pairing. Large or difficult positions may still exceed the search limits.

Note: The maximum number of participants is 60.

Once a round is confirmed, an incorrectly recorded result can be corrected through the GUI, provided that a tournament backup was previously created using the "Save Tournament" function.

Not implemented: acceleration, arbitrary additional pairing restrictions, adjournments, or an administrative workflow for altering published pairings and correcting archived results. The built-in tests are developer regression tests, not the official FIDE endorsement suite.
